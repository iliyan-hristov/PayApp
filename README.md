# payapp

Java Spring Boot web application for digital wallet management, money transfers and user account administration.

# About

PayApp is a Java Spring Boot web application that simulates a digital wallet platform.

Users can register, manage personal wallets, perform money transfers and view transaction history through a secure web interface.

This project was developed during the **Spring Advanced** course at **Software University (SoftUni)** and later refined as part of my Java Backend portfolio.

# Features

- User Registration
- Login
- Authentication
- Wallet Management
- Money Transfers
- Transaction History
- User Profile
- Input Validation
- Exception Handling
- MVC Architecture

# Technologies

- Java
- Spring Boot
- Spring MVC
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- Maven

# Architecture

Controller -> Service -> Repository -> Database
